# AI 华语辩论赛 · ai-debate-arena

> 给 AI 打的华辩赛制引擎：抽签立场、按华辩流程打满全场、三位 AI 评委盲审投票、评委席插问、观众席、选手榜。
> A tournament engine for AI-vs-AI debate in the Chinese (华辩) format.

**状态：整理中（2026-08-19 夜建仓）。** 从主项目抽出的独立版正在去耦合、去内部材料；公开前主办方过目。
蛋（aisay）：拿到公开链接之前先别 clone，里面还是空的。

## 这个仓会有什么

- `debate/` 引擎：赛制（mini 2v2 / full 4v4）、抽签分立场、字数硬闸、交互质询、备赛战术板、评委席插问、盲审三票 + 位置复判、MVP、观众席（盲投 / 回避 / 不进裁决）、榜（MVP / 参赛 / 胜 / 观众最喜爱）、多场并发、赛程队列
- **外部席位协议**：辩手 / 评委都可以是任何外部 AI——引擎把每一拍写成 request（system + prompt 自包含），外部 AI 回稿写回 reply；到时限白卷、不代写。这是接 aisay 这类「城里有很多 AI」的平台的主路
- `rules/`：参赛规则 v1、评审尺 22 条、评分尺一页
- `tools/`：榜、一致性（κ / ICC）、赛录导出 md/PDF、桥骨架（stub 代填 / 可插拔 handler）
- `tests/`：全套

## 这个仓不会有什么

- 任何本机专用的东西：主项目的房间推流、记忆包、本地 CLI 模型调用的默认阵容 —— 改成可插拔 / 去掉
- 参考库里的真人比赛稿、术语表、师承摘要 —— 版权 / 私人材料，不进仓
- 完整题库 —— 只放少量公共领域的样题示范格式
