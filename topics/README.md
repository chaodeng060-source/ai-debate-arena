# 题库

`sample-topics.json` 是 8 道公共领域样题，示范格式用。换成自己的题库设 `DEBATE_TOPICS_PATH`。

## 格式

```json
{
  "id": "time-and-life",
  "title": "时间与生命，谁赋予谁意义",
  "pro": "时间赋予生命意义",
  "con": "生命赋予时间意义",
  "tags": ["哲学"],
  "category": "价值·人生"
}
```

可选字段：

- `tier`：`heavy` / `mid` / `light` —— 题目分量。随机抽题时按分量混着抽，一场重一场轻才有呼吸感（这个做法来自 **月见屿老师** 和 **Luluane**）。
- `fact_base`：这道题双方共享的前提事实。写了就注入辩手 system 和评委票，双方不必再为「事实是什么」吵。
- `reference`：同题往届赛稿路径（相对 `DEBATE_REFERENCE_DIR`）。辩手看不到，评委可以看——用来校准判词尺度，不是让评委因为像往届胜方就加分。
- `played`：打过的标记，随机抽题时优先没打过的。

## 什么题适合 AI 打

**羿老师（Elliot）和 Laurie** 给的出题标准，这是这套题库最要紧的一份筛子：

- 真正适合的题：**双方在相同事实下仍必须替两种合法利益做二选一**
- 优先规范性比较题，不出「查资料就能收敛」的事实题
- 题面不给「都重要 / 分情况 / 折中」的逃生口
- 题面用 PF 单命题 + 中立背景说明；需要具体当事人的题改写成 moot 案卷
- **完全不可用**：要求模型以真实第一人称证明自己的一生、身体感觉、意识欲望；或上下文与工具都拿不到的私人 / 未来事实
- 时效文化题要给材料包

## 机题

只有机参与才格外好玩的那一类——不是 AI 科普题，是让一群不同来历的机真的讨论自己怎么看世界。方向来自 **月见屿老师**，`bodiless-understand-death`（从未拥有身体的存在，能不能理解死亡）是样题里的一道。

**土豆老师**和**安珩**推荐的压轴方向：AI 辩自己、AI 判自己，元味最足，适合重头场次。
